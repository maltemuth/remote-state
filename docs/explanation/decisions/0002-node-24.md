# 0002. Require Node.js 24

Status: Accepted
Date: 2026-09-29

## Context

The project ran on Node.js 20, which reached end-of-life in April 2026. Updating the dependencies required choosing a minimum version: it determines the `engines` field, the `@types/node` major version, and which Node features the code may use.

## Decision

Node.js 24, the active long-term-support line, is the minimum. `engines` is `>=24` in every package, `@types/node` is `^24`, and `.nvmrc` pins the exact version the project is tested on.

## Alternatives considered

- **Node.js 22.** The oldest supported LTS line at the time, maintained until April 2027. It would reach more users, but it's closer to end-of-life, and there are no known users to accommodate yet.
- **Staying on Node.js 20.** Rejected, because it no longer receives security fixes.

## Consequences

- CommonJS code can `require()` the ESM library, which Node 24 supports ([0004](0004-esm-with-jest.md)).
- Anyone on Node.js 22 or older can't use the library.
